# Hexanovate

A modern, component-rich UI framework built with React, TypeScript, and Tailwind CSS. Hexanovate provides an extensive collection of pre-built, accessible components designed for rapid application development.

## 🎯 Features

- **Rich Component Library**: Comprehensive set of UI components including accordion, alert dialogs, avatars, modals, dropdowns, and more
- **TypeScript Support**: Full TypeScript support for better type safety and developer experience
- **Tailwind CSS**: Utility-first CSS framework for rapid styling
- **Radix UI Integration**: Headless UI components with excellent accessibility
- **Material UI**: Professional Material Design components
- **Responsive Design**: Mobile-first, responsive component architecture
- **Animation Support**: Built-in animation utilities with Motion library
- **Form Handling**: Integrated with React Hook Form for powerful form management
- **Data Visualization**: Charts and graphs with Recharts
- **Drag & Drop**: React DnD for interactive drag-and-drop interfaces

## 📋 Prerequisites

- Node.js 18+ (or compatible version)
- npm or pnpm package manager

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/ThirdMeta-Dev/Hexanovate.git
cd Hexanovate

# Install dependencies
npm install
# or
pnpm install
```

### Development

```bash
# Start the development server
npm run dev

# The application will be available at http://localhost:5173
```

### Build

```bash
# Build for production
npm run build

# The compiled files will be in the dist folder
```

## 📦 Key Dependencies

- **React 18.3**: Core library with DOM utilities
- **TypeScript**: Type safety and better DX
- **Tailwind CSS 4.1**: Utility-first CSS framework
- **Radix UI**: Accessible, unstyled components (20+ components)

- **React Router 7**: Client-side routing
- **Supabase 2.104**: Backend database and authentication
- **Recharts 2.15**: Data visualization library
- **Framer Motion 12.23**: Animation library
- **React Hook Form 7.55**: Form state management
- **Lucide React**: Icon library
- **Embla Carousel**: Carousel/slider component
- **React DnD**: Drag and drop utilities
